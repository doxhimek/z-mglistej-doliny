STRONA: Z MGLISTEJ DOLINY FCI

Jak uruchomić na telefonie:
1. Rozpakuj ZIP.
2. Otwórz folder w Acode albo TrebEdit.
3. Kliknij index.html.
4. Wybierz Preview / Podgląd.

Najważniejsze pliki:
- index.html — strona główna
- o-hodowli.html — opis hodowli
- o-rasie.html — opis rasy
- psy.html — psy i suki hodowlane
- mioty.html — planowane mioty
- galeria.html — galeria
- kontakt.html — kontakt
- assets/css/style.css — wygląd strony
- assets/js/script.js — menu hamburger
- assets/img/logo-z-mglistej-doliny.png — logo

Jak zmienić logo:
1. Wgraj nowe logo do assets/img/
2. Nazwij je logo-z-mglistej-doliny.png
3. Albo zmień ścieżkę w HTML w miejscu <img src="assets/img/logo-z-mglistej-doliny.png">

Jak dodać zdjęcie psa:
1. Wgraj zdjęcie do assets/img/
2. W pliku psy.html znajdź komentarz "KARTA PSA".
3. Zastąp blok:
   <div class="dog-photo"><span>TU DODAJ ZDJĘCIE PSA</span></div>
   kodem:
   <img src="assets/img/twoje-zdjecie.jpg" alt="Opis psa">

Powodzenia!
